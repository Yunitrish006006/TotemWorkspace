## 結果定義

- **PASS — automated**：目前工作樹的測試或固定 validator 直接覆蓋該契約。
- **PARTIAL**：自動化覆蓋通過，但所列原生 host/Gateway 情境未以目前來源重新實測。
- **NOT RUN**：目前沒有可核對的執行結果；不能以 mock、舊 task note 或未部署的功能推定成功。
- **FAIL**：目前證據顯示不符合契約。此輪沒有已知 FAIL；這不會把 PARTIAL／NOT RUN 提升成 PASS。
