## 主要功能群

- **TotemAlchemy**：材料獨立效果機率、多效果釀造、營火煉藥鍋、研究樣本與可擴充基底。
- **TotemAutomata**：安全分類、結果導向熔爐投料、採集工作區、共享背包、深度遮擋工作區／容器連線與選配 LLM 規則。
- **TotemCore**：版本化 API、Migration、Manual Registry、Friendship、EventBus、Observer provider API，以及無狀態的方塊／長方體／兩點實線世界輪廓。
- **TotemDiscordBridge**：聊天／玩家事件、管理稽核、狀態／Presence、遊戲內設定及隱私邊界。
- **TotemEnchanting**：雕紋書櫃權重、30–64 品質曲線、粒子回饋與節肢剋星目標擴充。
- **TotemExcavation**：兩次蹲下左鍵選區、Core 深度遮擋選區輪廓、bounded 範圍挖掘、副手相容與重型戰鬥定位。
- **TotemLocksmith**：Root 網路拓撲、玩家／鑰匙權限、自動化邊界與破壞稽核。
- **TotemNexus**：磁石節點、傳送地圖、材料 profile、Server 權威傳送陣方塊診斷、好友目標與死亡節點管理。
- **TotemRemnant**：四階背包、十種擴充、原版物品欄側欄、死亡背包與防巢狀安全。
- **TotemVanillaTweaks**：語意 Observer View、容器整理、書櫃／講台、混凝土與自動化經驗修正。
- **TotemVillagers**：實體庫存交易、專職工作區、Woodcutter、村莊物流與建築安全。

DeadRecall 已停止維護，不屬於本總表的現役模組。
